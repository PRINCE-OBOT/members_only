# Members Only

A private clubhouse app where users can create anonymous messages.

Built as part of the [The Odin Project](https://www.theodinproject.com/lessons/node-path-nodejs-members-only) curriculum to practice authentication, authorization, sessions, and role-based permissions.

---

## Features

* User signup and login
* Password hashing with bcrypt
* Authentication using Passport.js
* Session-based login system
* Create and view messages
* Secret member passcode
* Admin-only delete functionality
* Conditional UI rendering based on user role

---

## Tech Stack

* Node.js
* Express.js
* PostgreSQL
* Passport.js
* EJS
* CSS

---

## User Roles

### Visitor

* Can read messages anonymously

### Logged-in User

* Can create messages

### Member

* Can see message authors and timestamps

### Admin

* Can delete messages
